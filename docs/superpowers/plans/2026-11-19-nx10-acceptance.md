# NX10 悬浮窗 真机验收记录

> 用法：在 NX10 里装好插件后逐条执行，把结果写在「结果」列。
> 前置：`build.cmd` 全绿；`install\install.ps1 -UserDir <UGII_USER_DIR>`；重启 NX10。

| # | 场景 | 期望 | 结果 |
|---|---|---|---|
| 0 | NX10 启动 | 不报错；任务管理器里有 `NxGeo.Overlay.exe` | |
| 1 | 点选面 | 浮窗 ≤100ms 出现，显示 类型/tag/颜色/包围盒/面积/周长 | |
| 2 | 点选边 | 显示 类型/tag/颜色/包围盒/长度 | |
| 3 | 点选体 | 显示 类型/tag/颜色/包围盒，稍后补 体积 | |
| 4 | 点空白取消选择 | 浮窗立即隐藏 | |
| 5 | 无工作部件（NX 刚启动） | 不弹错；浮窗不显示 | |
| 6 | 选中后删除该对象 | 浮窗隐藏或 note 显示「对象已删除」，NX 不崩 | |
| 7 | 旧浮窗 + 新插件（协议版本不符） | 浮窗显示「协议版本不符，请重启 NX」，不显示错位数据 | |
| 8 | 150% 缩放 + 双屏 | 浮窗定位不飘、不出 NX 窗口 | |
| 9 | Alt+` 切换点穿 | 点穿时能点到后面的模型；再按恢复可交互 | |
| 10 | 连续切换对象 10 分钟 | 无崩溃、无明显卡顿、内存不持续上涨 | |
| 11 | 关闭 NxGeo.Overlay.exe 进程 | 下次选择不会自动恢复（v1 已知限制），重启 NX 恢复 | |
| 12 | 关闭 NX | 浮窗进程随之退出（Job Object） | |

## 已知限制（v1）

- NX10 无公开 hover 回调：当前是**选择驱动**（点选才显示），鼠标悬停不触发。
- 浮窗被手动结束后不会自动重启（需要重启 NX 或后续版本加心跳）。
- 颜色只显示 NXColor 索引，未换算 RGB。
- 同一对象连续被选中（tag 不变）不会刷新数值，改了模型后需点选别的对象再点回来。
